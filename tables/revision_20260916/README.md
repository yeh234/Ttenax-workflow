# Revised figure metric exports

These 15 TSV files were generated on Biodragon by the Figure 2–6 scripts version `20260916.1`. The files are copied without changing their contents. They include assembly/polishing metrics, depth classes, annotation completeness/evidence, protein-family counts, and multi-omics/proteomics summaries.

The scripts are in `scripts/figure_plotting_scripts/`. Run them from the full analysis project root with the original inputs described in each script. The source-path columns document those analysis inputs; they do not indicate that the complete analysis directories are included in this GitHub repository.

The original `tables/Figure1_source_data.tsv` through `tables/Figure6_source_data.tsv` belong to the v1.0.0 snapshot and are retained separately for traceability. Figure 1 in the current revision is a schematic and emits no additional TSV.
