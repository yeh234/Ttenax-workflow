# Ttenax-workflow

Reproducible assembly, annotation, evidence-integration, validation, and figure-generation workflows for the *Trichomonas tenax* strain Hs-4:NIH (ATCC 30207) genome resource.

## Repository accessions

- NCBI Assembly: [GCA_061597355.1](https://www.ncbi.nlm.nih.gov/datasets/genome/GCA_061597355.1/)
- WGS: JCCIQK000000000; version described: JCCIQK010000000
- BioProject: PRJNA1457677; BioSample: SAMN57469269; SRA Study: SRP694902
- PRIDE/ProteomeXchange: [PXD084213](https://www.ebi.ac.uk/pride/archive/projects/PXD084213), DOI [10.6019/PXD084213](https://doi.org/10.6019/PXD084213)
- Zenodo annotation and source-data DOI: [10.5281/zenodo.22979861](https://doi.org/10.5281/zenodo.22979861)

## Repository contents

- `SOP/`: command-level assembly, annotation, STAR intron-support, and multi-omics procedures.
- `scripts/`: identifier conversion, evidence-table construction, and Figure 1–6 plotting code.
- `annotation/`: GenBank-synchronized GFF3, GTF, CDS, protein, identifier mapping, and compact STAR-support files under stable repository paths.
- `tables/`: supplementary tables, figure source data, the complete annotation table, contig status, and GenBank crosswalks.
- `data/contamination_screening/`: FCS-GX, FCS-adaptor, and NCBI contamination-screening reports.
- `docs/`: evidence-field definitions and plotting-input documentation.
- `software_versions.tsv`: software, database, and model versions used in the study.

Large raw reads, alignments, tool indexes, and working directories are stored in the cited public repositories or regenerated by the documented workflows. They are not duplicated in this source-code repository.

## Genome assembly and annotation resources

- The ≥15 kb structural backbone is archived as `flye_len15k/assembly.fasta` in Zenodo.
- The complete 33,845-row annotation/evidence table is available in Zenodo and as `tables/Ttenax_comprehensive_annotation_table.tsv.gz` here; field definitions are in `tables/Ttenax_comprehensive_annotation_columns.tsv` and `docs/EVIDENCE_FIELDS.md`.
- Per-contig length, depth, classification, and retain/remove status are in `tables/Ttenax_contig_status.tsv` and Supplementary Table S6.
- Exact released filenames, repositories, accessions, identifier namespaces, and intended uses are listed in Supplementary Table S7.
- Contamination-screening reports and their interpretation are in `data/contamination_screening/`.

## Stable paths and versioning

Repository paths use purpose-based names and do not encode revision dates. Git commits, tags, and GitHub Releases record version history. Established annotation filenames retain their original `v1` suffix so links and workflow commands remain stable.

## Figure generation

The plotting scripts accept an optional output prefix. Run them from a project directory containing the relative inputs listed in `docs/PLOTTING_INPUTS.tsv`.

```bash
Rscript scripts/figure_plotting_scripts/plot_figure1_workflow.R figures/Figure1_workflow
Rscript scripts/figure_plotting_scripts/plot_figure2_assembly_strategy.R figures/Figure2_assembly_strategy
Rscript scripts/figure_plotting_scripts/plot_figure3_depth_validation.R figures/Figure3_depth_validation
Rscript scripts/figure_plotting_scripts/plot_figure4_annotation_completeness.R figures/Figure4_annotation_completeness
Rscript scripts/figure_plotting_scripts/plot_figure5_family_comparison.R figures/Figure5_family_comparison
Rscript scripts/figure_plotting_scripts/plot_figure6_multiomics_support.R figures/Figure6_multiomics_support
```
